# フレグランス手帖（Sillage）

香水コレクションを、写真・香調・残量で手帖のように整えるためのアプリです。集めた香りが増えるほど「どれをいつ使うか」「もう似たのを持っていないか」「あと何日で使い切るか」が分かりにくくなります。フレグランス手帖は、所持ボトルを一覧の液面ゲージで見渡し、今日の一本を提案し、うっかりの重複購入を防ぎます。

香水好き・コレクター本人のための道具です。ブラウザだけで動き、記録はすべて使っている端末の中にとどまります。アカウント登録はいりません。

## できること

- **ボトルを登録する** — 香水名・ブランド・香調（8つのオルファクティブ・ファミリー）・残量・容量・季節/シーン（TPO）タグ・香りのピラミッド（トップ/ミドル/ラスト）・写真・購入日・価格を記録します。
- **コレクションを見渡す** — 各ボトルを液面の高さで残量が分かるバイアルとして並べ、使い切りが近い順に表示します。香調スペクトル帯でしぼり込めます。
- **今日の一本を提案** — 季節・最近使っていないか・残量から、今日つける一本をおすすめします。
- **重複購入ガード** — 新しく登録するとき、すでに持っている似た香り（同じブランド・同じ香調・似た名前）を知らせます。
- **使い切り予測** — 使った記録や使用頻度から、いつ頃なくなるかの目安を出します。
- **バックアップ** — コレクションをJSONファイルに書き出し・読み込みできます（機種変更や共有に）。

## 使い方

1. 「迎える」から最初のボトルを登録します。香調と残量だけでも始められます。
2. 使った日は「つけた」を押すと残量が少し減り、使用履歴が残ります。
3. 一覧のバイアルは残量を表し、詳細では香りのピラミッドと使い切り予測日を確認できます。
4. ときどきバックアップを書き出しておくと安心です。

## 制限事項

- 記録はこの端末のブラウザ内にのみ保存されます。別の端末とは自動同期しません（バックアップの書き出し/読み込みで移せます）。
- ブラウザのデータを消去すると記録も消えます。写真はバックアップJSONには含まれません。
- 使い切り予測は入力した使用頻度や履歴にもとづく目安で、実際の使用量とは差が出ます。
- サイト改善のため、匿名・cookieless のページ閲覧数のみ計測しています（香水の記録そのものは送信しません）。

## 開発

Next.js（App Router）。`out/` への static export で配信します。

```bash
./setup.sh                 # 依存の導入
pnpm dev                   # http://localhost:3000
pnpm build                 # out/ に静的書き出し
pnpm test                  # ドメインロジックのテスト
```
